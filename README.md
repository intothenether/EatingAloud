# Eating Aloud Blog

Modern responsive landing page based on provided mobile design. Built with:
- HTML5
- Sass (SCSS)
- TypeScript

## Setup

1. `npm install`
2. `npm run build`
3. Open `index.html` or run a static server (e.g. `npx serve .`).

## Development

- `npm run watch:css`
- `npm run watch:ts`

## Output

- `styles/main.css`
- `scripts/dist/main.js`

## Notes

- The hero card uses a placeholder image URL. Replace with your assets as needed.
- The hamburger toggle is ready for extension to a mobile nav drawer.
